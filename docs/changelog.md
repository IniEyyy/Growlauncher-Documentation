## Version 7.0.10

**GrowLauncher Rebuild Release - Big Update!**

**Theme:** The Rare Owl

**Message from Developer:**
Hello everyone! 👋
It has been 2 months since the initial rebuild. The initial planning was to rebuild only the native parts, but after much consideration... the Growlauncher interface had become flat and outdated... so to avoid boredom, I decided to create a completely new interface...

So I chose an Owl or ghost bird theme, because that's the main point! :v

It's not just about the appearance, but I've rebuilt everything based on user reports and feedback, including small detailed features that most people don't notice... I hope you all like the new interface and new features!

**Major New Features:**
- New UI for Growlauncher with customizable color
- Smooth animation in Growlauncher
- Display Username and Role In-Game menu
- Script Hub now is opened for public, you can upload or download script easily now, has custom encrypt
- Redesigned Layout
- Now features has description
- Important features now has Autosave
- Moderator Exit Features
- All features algorithm is rebuilt
- New UI for lua manager

- And so much more !!!
