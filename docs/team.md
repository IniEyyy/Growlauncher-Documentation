## Contributors

We welcome contributions from the community! Here are the people who have helped improve Growlauncher and its documentation.

#### How to Contribute

1. **Report Issues** - Found a bug? [Open an issue](https://github.com/IniEyyy/Growlauncher-Documentation/issues)
2. **Submit PRs** - Have improvements? [Submit a pull request](https://github.com/IniEyyy/Growlauncher-Documentation/pulls)
3. **Improve Docs** - Help us make documentation better
4. **Share Examples** - Contribute example scripts and tutorials

#### Contribution Guidelines

- Follow the existing code style
- Provide clear commit messages
- Update documentation for new features
- Test your changes thoroughly
